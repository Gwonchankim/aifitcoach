# 제품 컨텍스트 (무엇을/왜) — AIFITCOACH (AFC)

## 한 줄
사용자의 세트별 실측(무게·반복·RIR)을 기록하면, 다음 세션의 무게·반복·세트수를 자동으로 추천하는
**기록 기반 폐루프 오토레귤레이션 운동 코칭 웹앱**. 한국 시장, 목표 3종(다이어트/근비대/스트렝스).

## 핵심 기능·UX
- 세트 로깅+완료 체크, 휴식 타이머 팝업(+시간 증가/종료), 데일리 루틴 편집(추가/삭제/교체), 운동 종료로 기록·추천, 대시보드. 상세: `FEATURES_UX.md`.

## 차별점(핵심)
- 로깅 앱(기록만)과 AI 생성 앱(불투명한 자동 생성) 사이의 빈틈을,
  **근거 있고 설명가능한 기록 기반 자동 코칭**으로 메운다.
- 모든 추천에 근거(reason_code)를 노출 → 신뢰. 운동과학 기반 규칙 → 정확도·안전.
- 기록이 쌓일수록 추천이 정교(데이터 해자).

## 목표 지표
- North Star = 주간 운동완료율 × 추천 수락률.
- 완료율 ≥70%, 추천 수락률 ≥60%, D30 ≥35%, 통증 중단율 ≤5%.

## 사용자
- 한국 20~40대, 헬스장 웨이트 초중급자. 목표별 프로그램 자동 생성 + 세트 단위 진행 추천을 원함.

## 범위(MVP → 이후)
- MVP(P0): 온보딩·프로그램 생성·오프라인 세트 로깅·더블 프로그레션 추천·세션 요약·기본 분석·구독.
- P1: RIR 오토레귤레이션·RIR 캘리브레이션 튜토리얼·볼륨 자동조정·디로드.

원본 상세: 팀 드라이브의 PRD v1.1 / MVP 상세 스펙 v1.1.
